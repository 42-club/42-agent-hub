## 复现与回滚

共享数据库迁移在 `../42-agent-service/supabase/migrations`。旧前端目录中的 Supabase 迁移仅为历史源库记录，不用于新共享库。

本机私有迁移快照、复制清单、哈希校验、测试脚本和源库解冻 SQL 位于 `/tmp/42-club-migration-20260924`，包含敏感数据，不得提交版本库。正式数据仍保留在 Supabase 源库及目标库；不要依赖临时目录作为唯一备份。

生产切换后若回退旧应用，必须先处理共享库新增数据的反向同步，再恢复旧库写入。直接回退 Vercel 别名不等于安全的数据回滚。
